GENERADOR CRUD LARAVEL
======================

La guia de uso completa, con pasos reales para preparar proyectos, configurar
las fuentes, generar Backend/Frontend, revisar configuracion manual e iniciar
los servidores, esta en el README.md de la raiz del repositorio.

Comandos desde la raiz del ejercicio:

  php .tools/.crud/generate.php all
  php .tools/.crud/generate.php start

La estructura de este repositorio usa ".tools/.crud" (punto antes de crud).
Las fuentes originales configuradas en config.php son requeridas para adaptar
los CRUD; el generador no las reemplaza por codigo generico ni modifica dichas
fuentes. Revise el README.md antes de copiar la herramienta a otro ejercicio.
